# PROBLEM DESCRIPTION
A Hotel Management System is a software application for hotel operations like room booking, guest management, service system and billing. Here the app allows the guest to book a room also request services, whereas the receptionist controls the check-in, check-out and bookings and the manager handles the billings and reports .The app also contains availability of rooms and the booking details using simple Java program.

# HOW TO RUN THE CODE
Step 1:Open terminal in your project folder(23CSE111_CaseStudy_D10) and run:
javac *.java
Step 2: Run the program
java Main
